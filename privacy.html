Privacy Policy — Shigatsudo Uploader

Last updated: November 13, 2026

1. YouTube API Services

Shigatsudo Uploader ("the Application") uses YouTube API Services. By using the Application, you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

2. Information the Application accesses

When you sign in with your Google account, the Application requests the OAuth 2.0 scope https://www.googleapis.com/auth/youtube.upload. It uses this permission only to upload video files that you select from your own PC to your own YouTube channel, together with the title, description, tags and privacy status you enter.

3. How information is stored

  • The OAuth access/refresh token is saved only on your own PC, in a JSON file in the same folder as the Application.
  • Upload history (file name, video ID, date) may be saved in a local JSON file on your PC.
  • No data is sent to any server operated by the developer. The Application communicates only with Google/YouTube APIs.

4. Sharing of information

The Application does not sell, share, or disclose any user data to third parties. It does not use cookies, analytics, or advertising.

5. Revoking access and deleting data

You can revoke the Application's access to your Google account at any time from the Google security settings page. You can delete all locally stored data by deleting the token and history JSON files from the Application's folder.

6. Changes

If this policy changes, the updated version will be posted on this page with a new "Last updated" date.
